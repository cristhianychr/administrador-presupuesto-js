# 💰 Administrador de Presupuesto

Aplicación web desarrollada como parte del curso **JavaScript Moderno: Guía Definitiva Construye +10 Proyectos**.

El proyecto permite administrar un presupuesto y registrar gastos mediante una interfaz interactiva, aplicando clases de JavaScript para organizar la lógica de la aplicación.

## ✨ Funcionalidades

- Definición de un presupuesto inicial.
- Registro y administración de gastos.
- Cálculo del presupuesto disponible.
- Actualización dinámica de la información.
- Interacción mediante formularios y eventos.

## 🚀 Ejecución local

Clona el repositorio:

```bash
git clone https://github.com/cristhianychr/gasto-semanal-js.git
```

Accede a la carpeta:

```bash
cd gasto-semanal-js
```

Abre `index.html` en tu navegador.
